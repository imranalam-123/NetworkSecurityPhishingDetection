# Network Security Phishing Detection

## Overview
A machine learning-based phishing website detection system built using FastAPI, Streamlit, MongoDB, and Scikit-Learn.

## Features
- Data Ingestion
- Data Validation
- Data Transformation
- Model Training
- FastAPI Backend
- Streamlit Frontend
- CSV Batch Prediction
- Prediction Visualization

## Tech Stack
- Python
- FastAPI
- Streamlit
- MongoDB Atlas
- Scikit-Learn
- Pandas
- MLflow
